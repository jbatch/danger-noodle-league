## Scenario

The harness creates deterministic 2-, 4-, and 8-player rooms on the empty arena. Every snake has a mature 117-point trail. The `busy-combat` case additionally includes two fireballs and one grenade/blast per player, an active rail, 24 recent events, four world pickups, and a detached 117-point trail.

Each timing reports 600 measured operations after 100 warmups. Bandwidth is projected from the measured UTF-8 snapshot payload at the production target of 20 snapshots/second. `deflate bytes` is an estimate using raw DEFLATE level 6; WebSocket compression is not enabled in this baseline.

## Interpretation

- The current protocol resends the complete room state to every client at 20 Hz, so room egress grows approximately with the square of player count: more players make each snapshot larger and create more recipients.
- The deflate column shows the upper-bound opportunity from generic compression, but CPU cost, latency, proxy support, and already-compressed traffic still need to be measured before enabling it.
- The largest likely wins are compact/delta trail encoding, sending event data once, quantizing numeric state, and applying backpressure so superseded snapshots are dropped instead of queued.
- These local numbers deliberately exclude Internet latency, packet loss, TLS framing, TCP retransmission, and browser rendering. The live `/telemetry` endpoint records real-server snapshot size/encode cost, tick time, event-loop lag, socket buffering, RTT, and browser-reported cadence/jitter/gaps during smoke tests.

## Reproduce and compare

Run the following command on the same machine and runtime before and after a networking change:

```bash
npm run benchmark:network
```

The command updates this Markdown report and `docs/network-performance-baseline.json`. For a fair comparison, retain the previous JSON or commit it before running the optimized build. During a real playtest, sample `http://<server>/telemetry` before, during, and after the session; the endpoint is process-local and resets when the server restarts.
